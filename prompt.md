This repository contains Terraform to bring up two AWS EKS clusters. One runs ArgoCD, the other runs a production workloads on a 2-3 node cluster. The workloads will involve sensitive data, so are in a private VPC. Egress to the internet is only possible via an EC2 transparent Squid layer 7 proxy because AWS Network Firewall is too expensive. This is done as an EC2 instance to support future EC2 workloads outside EKS. Traffic is transparently routed to this proxy using the subnet route table. Traffic to AWS APIs is done using VPC private endpoints. EKS supports load balancers, the main types of storage volumes (object, block, file), and includes Cilium in a configuration which supports Cilium network policies and the Gateway API.
